# pca-dimensionality-reduction
Applied Principal Component Analysis (PCA) to reduce high-dimensional data and visualize patterns in a 2D space.

This project applies Principal Component Analysis (PCA) to reduce high-dimensional data and visualize patterns in a simplified 2D representation.

## Objective
To transform a dataset with multiple variables into a lower-dimensional space while preserving the main structure and variance.

## Methodology
- Data centering (mean subtraction)
- Covariance matrix computation
- Eigenvalue and eigenvector decomposition
- Selection of principal components
- Projection of data into 2D space

## Key Concepts
- Eigenvalues → importance of each component  
- Eigenvectors → directions of maximum variance  
- Dimensionality reduction from 6D to 2D  

## Results
- Successfully reduced dataset complexity  
- Visualized relationships between data points  
- Preserved most of the variance in fewer dimensions  

## Technologies
- Python
- NumPy
- Matplotlib

## What I learned
- Mathematical foundation of PCA  
- Eigen decomposition and covariance matrices  
- Dimensionality reduction techniques  
- Data visualization and interpretation
